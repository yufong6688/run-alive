# RunAlive

銀髮族課程入口網站（純靜態，GitHub Pages 部署）。

> 歷史沿革：本網站由小賀復刻自舊版 happySenior 教學網站（該母站已停用，未來可能刪除），2026-08-13 品牌更名為 **RunAlive**，現為網站主力。

線上網址：https://yufong6688.github.io/run-alive/

## 內容

| 路徑 | 說明 |
|---|---|
| `index.html` | 首頁：5 種版面 × 5 種配色、照片輪播、課程模組、側邊工具箱、最新消息 |
| `default.txt` | 拍手節奏工具預設設計檔（36 聲音節奏） |
| `assets/` | 商標圖檔 |
| `tools/` | 教學工具：入口頁、年齡計算、36 聲音節奏 |

## 最新消息公告後台

「最新消息」區塊由 GitHub Issues 即時驅動：

- 新增公告：在 [Issues](https://github.com/yufong6688/run-alive/issues) 建立 Issue，標籤選「網站公告」（含 `活動日期：YYYY-MM-DD` 或 `日期：` 可指定顯示日期）
- 下架公告：關閉該 Issue 即可

## 部署

GitHub Pages：main 分支根目錄。更新方式：修改後 push 即可自動上線。
